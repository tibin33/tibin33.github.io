树莓派个人网站：从零到公网

纯静态 · 自托管 · 公网可访问

背景。一直想把个人网站掌握在自己手里。树莓派 3B 只有 1GB 内存，跑 WordPress 这类动态站点会很吃力，但纯静态站点对它来说绰绰有余——没有数据库、没有运行时框架，靠 Nginx / Caddy 直接输出文件即可，内存占用极低、SD 卡损耗也小。

部署形态。网站本体先托管在 GitHub Pages（无域名时期也能公网访问、可灾备）；等树莓派与外接硬盘就绪后，再把资源下载服务迁移过去。两套环境共用同一份手写 HTML，内容始终一致。

成果。单页 HTML+CSS+JS 控制在 300KB 以内，首屏无需等待；全站展示图总量 ≤10MB。下载服务由 Web 服务器的 Basic Auth 承担口令校验，前端零依赖、零改动即可生效。
